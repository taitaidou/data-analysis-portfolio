## 分析到需求
已有样本活跃分层中一次性用户占51.77%，但该比例不等于流失率，也不能直接据此创建召回名单。它仅提示进一步研究回访与分层运营的方向。详见[原分析](../README.md)。

第一版回答：如何让运营人员按可解释规则选择候选人群，并通过审核后的任务演示一次召回流程？

现有八张汇总CSV不足以提供用户级名单、消息授权和送达记录。原型内100个虚构用户、活动资料和实验结果全部是模拟数据，与Firebase真实样本无关。AI按钮使用固定模板，没有调用模型。执行按钮只改变浏览器内存状态，不发送消息；刷新页面重置。没有服务器身份认证、定时调度、真实频控或真实实验分流。
