# 演示与验收

## 打开
下载本目录后双击prototype.html（core.js放在同目录）。可离线运行；也可在目录执行python -m http.server 8765后访问http://localhost:8765/prototype.html。GitHub本身不预览HTML应用。打印页面会展开全部四页，可另存PDF。

## 5分钟演示
1. 保持默认条件，点击预览；解释数据日期2026-10-01和模拟用户来源。
2. 在策略配置填写任务名，选择一条模板文案，设未来时间，以运营身份提交。
3. 切换审核人，在审核页查看配置后通过；切回运营模拟执行。
4. 再次执行应被拒绝；效果页是独立固定示例，不会因点击发送而变化。
5. 修改文案，检查审批失效；回到人群页预览、重新提交才能再次审核。

## 负向场景
- 未预览直接提交：拒绝。
- 未活跃阈值设999，预览0人：拒绝提交。
- 阈值设负值：拒绝预览。
- 时间设过去、文案为空或超过80字符：拒绝提交。
- 未审核执行、审核身份提交、运营身份审批：拒绝。
- 拒绝/取消后直接执行：拒绝。

## 检查方式与边界
test-core.cjs使用Node内置assert检查分层边界、空人群、校验、角色与状态、防重和修改失效；运行node test-core.cjs。不验证生产安全、网络回执或真实因果效果。原型是浏览器内存演示，没有持久化和后台。UI实际检查结果由上传时的验证记录补充。
