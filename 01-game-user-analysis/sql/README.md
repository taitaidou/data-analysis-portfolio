# 游戏项目 SQL

本目录保存项目提供的七份原始查询，使用 BigQuery GoogleSQL，数据表为 `firebase-public-project.analytics_153293282.events_*`。本次仅整理上传，未修改 SQL，也未连接 BigQuery 执行验证。

| 文件 | 内容 |
| --- | --- |
| `探索性分析.sql` | 事件分布、数据日期范围及明细样例；包含三个独立查询 |
| `dau.sql` | 每日活跃用户数、事件数与人均事件数 |
| `rolling wau.sql` | 当日及前六日的去重活跃用户数 |
| `D1andD7 留存分析.sql` | 按数据范围内首次出现日期构建 Cohort，计算 D1/D7 留存 |
| `版本表现分析.sql` | 版本覆盖人数、事件数、人均事件数及完成关卡人数 |
| `分群(设备，国家，活跃频次).sql` | 内容为设备,国家，活跃频次分群 |
| `关键行为漏斗分析及转化率.sql` | 各关键事件的去重用户数及人数比值；包含两个独立查询 |

## 使用说明

在有权查询公开数据集的 BigQuery 环境中运行。包含多个查询的文件可分段执行并分别导出结果。
