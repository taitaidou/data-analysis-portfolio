## 展示与数据说明

- 图片按用户提供的截图原样保存，部分图表存在滚动区域，截图不代表完整视图。
- 查询数据与口径见[数据说明](../data/README.md)和[SQL 说明](../sql/README.md)。现有 SQL 的留存观察期处理、事件先后顺序和用户分层阈值仍有待补齐；截图本身不用于证明这些口径已经修正。
- 版本用户可能跨版本重复，人均事件数或版本用户规模差异不能直接解释为版本的因果效果。
- 尚未提供 `.twbx` 工作簿文件；仓库现提供截图、查询、汇总 CSV 和在线入口。
