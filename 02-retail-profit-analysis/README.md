# 零售企业销售与利润分析

**工具：** MySQL、Python、Tableau  
**项目时间：** 2025.12–2026.02

## 分析目标

分析销售与利润结构，定位亏损品类、折扣相关的利润差异和区域退货差异。

## 数据与方法

依据项目描述，使用公开零售交易数据，关联订单、退货及区域负责人等表。具体来源与字段字典需随实际材料补充。

- 构建销售额、利润率、客单价及退货率等经营指标。
- 按地区、品类和折扣水平下钻，分析 Tables 品类亏损情况。
- 使用 Python 分析折扣与利润表现，并对比区域退货情况。

## 结果与交付

具体数值待代码复核后补充。分析建议包括复核亏损品类的定价与促销策略，以及按商品和订单结构排查区域退货差异；折扣相关性不作为因果证据。

## 复核与复现材料

- 数据来源、币种、交易时间范围与每张表的数据粒度。
- 多表关联键、关联前后行数和重复记录检查。
