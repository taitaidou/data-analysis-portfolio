## 显示与复现说明

- 原始 `profit_margin` 和 `return_rate` 字段按 SQL 口径已乘以 100；例如退货率 11.40 表示 11.40%，设置 Tableau 百分比格式前需除以 100。当前公开退货图数值轴未明确标出百分号，阅读时应按此单位理解。
- 整体利润率应为总利润除以总销售额，不应平均各月利润率。
- 订单数在多个子类别中可能重叠，不通过子类别订单数相加推算整体订单数或整体退货率。
- 公开看板以当前已发布状态为准，本次只更新 GitHub 入口、截图和说明，未修改 Tableau 工作簿。
- 导出表的日期标签覆盖 2023-01 至 2026-12，与简历中的项目时间不一致，日期是否重编码、是否为示例标签尚待确认；不视为已核实的真实交易发生时间。
- 尚未提供 `.twbx` 文件，也未提供 Python 分析代码或折扣分析结果表。
