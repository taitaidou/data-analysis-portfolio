# 电商平台用户行为分析与 RFM 用户价值分层

**工具：** SQL、Python、Pandas、Matplotlib

## 分析目标

梳理用户行为与购买转化路径，分析用户价值差异，形成分层运营建议。

## 数据与方法

依据项目描述，使用 SQL 提取、聚合用户行为数据，并用 Pandas 清洗与分析浏览、收藏、加购及购买行为。数据集来源、项目日期及字段定义需结合原始材料确认。

- 构建行为指标与转化漏斗。
- 在存在有效消费金额字段的前提下，根据最近购买时间、购买频次和消费金额开展 RFM 分层。
- 展示用户群体分布，提出维护、转化和召回建议。

## 结果与交付

具体人数、分层结果及图表待代码复核后补充。建议尚未通过实际运营实验验证。

## 复核与复现材料

- 数据来源、统计周期与行为字段说明。
- 消费金额字段来源或可靠计算方式；若无金额字段，应按实际情况使用 RF 分层。
- R 的统计基准日、F 的计数粒度、M 的汇总方式及退款处理规则。
- 分层阈值、八类群体规则与用户数校验。
- SQL、Python 运行顺序和结果图表。
