# 电商用户画像与价值分层｜学习整理项目

**原作者：代维**  
**来源：[和鲸社区原项目](https://www.heywhale.com/mw/project/69987eec9bb7c0d2d559ed2e)**  
**工具：** Python、Pandas、NumPy、Matplotlib、Seaborn、SciPy

本目录整理用户提供的原项目文本与代码，保留来源署名。当前交付为材料归档与 Notebook 代码整理，**不是已独立重跑验证的原创分析项目**。原数据 CSV 和原始图像尚未提供，具体来源与使用边界见 [ATTRIBUTION.md](ATTRIBUTION.md)。

## 项目目标

围绕用户属性、登录活跃、购买频次及消费金额开展画像分析与用户价值分层，展示描述性统计和相关性探索，并为后续运营验证形成候选方向。材料不含浏览、加购、购买的事件明细，本目录不宣称已完成转化漏斗或 SQL 取数。

## 数据与方法

原文附带的 `df.info()` 输出为 **1,000 行、15 列**，其中包含索引列 `Unnamed: 0`；原 CSV 未附，尚未独立核对。

代码分为以下部分：

1. 数据读取、缺失与重复检查，以及年龄、购买频次和消费金额筛选。
2. 性别、年龄、地域、兴趣和品类偏好画像。
3. 登录间隔直方图、KDE 曲线及邮件订阅群体停留时长对比。
4. 采用登录间隔、购买频次、总消费额完成五分评分与八类用户分层。
5. 对数值字段计算相关性矩阵并绘制热力图。

### 分层指标定义

| 指标 | 实际字段 | 评分规则 |
| --- | --- | --- |
| R 替代指标：登录新近度 | `Last_Login_Days_Ago` | 值越小得分越高，5至1分 |
| F：购买频次 | `Purchase_Frequency` | 值越大得分越高，1至5分 |
| M：总消费额 | `Total_Spending` | 值越大得分越高，1至5分 |

原代码先使用 `rank(method='first')`，再使用 `pd.qcut(..., q=5)` 打分。分数 **>=4** 定义为高，**<4** 定义为低，再组合成八类。R 使用登录间隔，是经典购买新近度的替代，不能改称最近购买时间；同值排名受原始行顺序影响，规则稳定性需复现检查。

## 材料核对与结论边界

原文部分叙述与代码输出存在冲突，完整说明见 [材料一致性核对](docs/material_review.md)。主要包括：

- 清洗叙述声称删除重复与负消费记录，但打印输出显示重复为0、清洗前后均1,000行。
- 平均订单价值与总消费的相关系数，打印输出为 **0.096705**，正文却写成 **0.967**，不能采用“极强正相关”的结论。
- 描述统计显示登录间隔最大29天，与正文“18%超过30天未登录”不一致。
- 缺少事件明细、统计周期和实验设计，不能从相关性或箱线图推出因果效果。
