# 公共健康行为数据糖尿病风险预测

**工具：** R、Shiny  
**项目时间：** 2022.10–2023.01

## 分析目标

使用公共健康行为数据开展糖尿病风险分类建模，比较模型表现并通过交互界面展示分析结果。本项目为数据分析与建模实践。

## 数据与方法

依据项目描述，使用 R 完成数据筛选、缺失值处理、变量转换及训练/测试集划分；使用 BMI、血压、胆固醇、年龄等特征构建决策树、逻辑回归、朴素贝叶斯和 KNN 模型，并探索 SMOTE、下采样与分类阈值调整。

## 结果与交付

使用 Accuracy、Precision、Recall、F1-Score 和 AUC 对比模型表现。具体数值待代码复核后补充。依据项目描述曾使用 Shiny 完成在线部署，当前未提供应用链接与源代码，整理后补充。
