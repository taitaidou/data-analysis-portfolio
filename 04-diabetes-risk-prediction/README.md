# 公共健康行为数据糖尿病风险预测

**工具：** R、caret、rpart、e1071、kknn、Shiny  
**项目时间：** 2022.10–2023.01（沿用既有简历记录，课程文件未提供可独立核对的项目日期）

## 项目目标

通过公共健康行为数据进行标签分类与模型比较，练习数据预处理、类别不平衡处理、性能评价和交互应用开发。本目录展示课程模型及历史报告材料，不用于医疗诊断或个人医疗决策。

## 数据与标签

本地输入文件 `public_health_behavior.csv` 经结构检查为 **96,892 行、25 列**。仓库仅保留[字段与标签计数](docs/data_profile.json)，不上传原始健康明细或个人级预测记录。数据来源、字段字典与使用许可尚需补齐。

原脚本将 `Diabetes_012 == 0` 映射为 `No`，其余值（原表中的1和2）合并为 `Yes`。因此，本项目的二分类正类以该代码定义为准，不直接等同于已验证的临床确诊或未来患病风险。

## 方法与代码

[原始 R 脚本](R/health_analysis_original.R)按原样归档，主要步骤包括：

1. 筛选健康、生活方式与人口属性字段，转换高血压、胆固醇、年龄、一般健康状态等变量，将BMI=99转为缺失并使用中位数填补。
2. 使用固定随机种子42，按标签进行70%训练集／30%测试集划分。
3. 针对不同模型选择特征，使用下采样、SMOTE或五折交叉验证等设置。
4. 计算Accuracy、Precision、Recall、F1和AUC，生成指标表与可视化。
5. 通过[Shiny原型](app/README.md)提供CSV上传、数据预览、模型选择、预测及下载界面。

| 模型 | 输入特征 | 原脚本设置 |
| --- | --- | --- |
| 决策树 | HighBP、HighChol、Age | rpart，训练集下采样，测试集选阈值 |
| 逻辑回归 | HighBP、BMI、Age、GenHlth | 哑变量、标准化、训练集SMOTE，测试集选阈值 |
| 朴素贝叶斯 | PhysActivity、Sex、GenHlth、HighBP | e1071，测试集选阈值 |
| KNN | GenHlth、BMI | 训练集抽5,000行，五折CV、SMOTE、中心化／标准化及邻居数调优 |

以上是原实现的记录，不意味着这些步骤均符合独立测试集评估规范。完整问题与修正方向见[评估口径说明](docs/evaluation_notes.md)。

### 1. 课程 PPT 报告指标

下表转录自[课程PPT第5页](reports/health_presentation.pptx)，对应图片和[机器可读CSV](data/reported/model_metrics_from_ppt.csv)已上传。**本次没有重跑R模型，这些是历史报告值。**

| 模型 | Accuracy | Precision | Recall | F1 | AUC |
| --- | ---: | ---: | ---: | ---: | ---: |
| Decision Tree | 0.644 | 0.309 | 0.699 | 0.429 | 0.681 |
| Logistic Regression | 0.687 | 0.349 | **0.732** | 0.472 | **0.775** |
| K-Nearest Neighbors | **0.779** | 0.379 | 0.244 | 0.297 | 0.640 |

在这份报告的三组记录中，逻辑回归AUC最高，较KNN高 **0.135**；KNN的Accuracy更高，但Recall较低，说明不同指标的排序并不相同。此处只比较报告所列数值，不宣称已得到可推广的算法排名或医疗有效性结论。

原R代码包含朴素贝叶斯，但PPT指标图未提供该模型的数值，因此没有补造第四行。

### 4. 评估限制

- 原脚本在全数据拟合缺失值填补器后才切分，存在测试信息泄漏。
- 决策树、逻辑回归、朴素贝叶斯用测试标签选阈值，再在同一测试集报告分类指标，不能称为完全独立的留出集评估。
- 各模型特征集和训练样本设置不同，比较的是具体实现组合。
- PPT包含K-means、生活方式回归和卡方检验等拓展内容，当前提供的R文件未实现全部探索。
- 未提供外部验证、概率校准或医疗应用效果数据。

这些限制影响结果可解释范围，应先修复训练、验证和部署流程，再用新结果更新简历、应用和报告。
