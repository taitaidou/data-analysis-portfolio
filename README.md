## 文件组织

每个项目按实际材料补充以下目录，无相关材料时不创建空文件：

- `data/`：可公开的样例、汇总数据及来源说明。
- `sql/`：清洗与指标计算 SQL。
- `notebooks/` 或 `R/`：实际运行的分析代码。
- `docs/`：指标口径、方法说明与分析报告。
- `tableau/`、`figures/` 或 `app/`：实际完成的看板、图表或 Shiny 应用。

只提交有权公开的数据。原始大数据通过来源链接与获取说明提供；不上传账号凭证、个人敏感信息或未经检查的打包数据。
